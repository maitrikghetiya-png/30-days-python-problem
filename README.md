# Python Conditional Statements – Practice Programs

## 📌 Project Overview

This project contains four Python programs designed to practice conditional statements, nested `if` statements, logical operators, and independent condition checking.


## 🛠️ Technologies Used

- Python 3
- VS Code or any Python-compatible editor

## ▶️ How to Run

1. Install Python 3.
2. Save each program in a `.py` file.
3. Open the terminal in the project directory.
4. Run the required program:

```bash
python3 filename.py
```

Replace `filename.py` with the name of your Python file.

## 🎯 Learning Outcomes

- Understand basic and nested conditional statements.
- Apply logical and comparison operators.
- Validate user input against multiple conditions.
- Implement admission, transaction, and employee eligibility rules.
- Understand the difference between independent and nested conditions.
