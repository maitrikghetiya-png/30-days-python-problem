# Python Conditional Statements – Practice Programs

## 📌 Project Overview

This project contains four Python programs designed to practice conditional statements, nested `if` statements, logical operators, and independent condition checking.

## 📚 Programs Included

### Q1. Admission Eligibility Checker

**Objective:** Check whether a student is eligible for admission based on marks and age.

**Conditions:**
- Marks must be at least 60.
- Age must be at least 18.
- Display an appropriate message based on the conditions.

**Concepts Used:** `if`, nested `if`, `input()`, type conversion.

### Q2. Smart Transaction Validator

**Objective:** Validate a bank withdrawal transaction.

**Conditions:**
- Withdrawal amount must be positive.
- Withdrawal amount must be a multiple of ₹100.
- Account balance must be sufficient.
- Print `Transaction Successful` only when all conditions are satisfied.

**Concepts Used:** Independent `if` statements, logical operators (`and`), arithmetic operators (`%`).

**Restriction:** Do not use `elif` or `else`.

### Q3. Employee Bonus and Promotion System

**Objective:** Evaluate employee eligibility for bonuses, promotions, and performance recognition.

**Conditions:**
- **Bonus Eligible:** Experience ≥ 3 years, rating ≥ 8, and attendance ≥ 90%.
- **Promotion Eligible:** Experience ≥ 5 years and rating ≥ 9.
- **High Performer:** Rating ≥ 9.
- **High Salary Band:** Salary > ₹1,000,000.

**Concepts Used:** Independent `if` statements and logical operators.

Multiple messages can be displayed when an employee satisfies multiple conditions.

### Q4. Nested Admission and Scholarship System

**Objective:** Check college admission eligibility and scholarship qualification.

**Admission Requirements:**
1. Student age must be at least 18.
2. Entrance exam score must be at least 75 out of 100.
3. Class 12 percentage must be at least 60%.

**Scholarship Requirements:**
- Admission must be approved.
- Family annual income must be at most ₹300,000.
- Entrance exam score must be at least 90.

**Concepts Used:** Nested `if` statements and conditional logic.

The scholarship check runs only after admission is approved.

## 🛠️ Technologies Used

- Python 3
- VS Code or any Python-compatible editor

## ▶️ How to Run

1. Install Python 3.
2. Save each program in a `.py` file.
3. Open the terminal in the project directory.
4. Run the required program:

```bash
python3 filename.py
```

Replace `filename.py` with the name of your Python file.

## 🎯 Learning Outcomes

- Understand basic and nested conditional statements.
- Apply logical and comparison operators.
- Validate user input against multiple conditions.
- Implement admission, transaction, and employee eligibility rules.
- Understand the difference between independent and nested conditions.
